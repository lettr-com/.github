## Lettr — Email API for Developers

Send transactional emails with a clean REST API, drag-and-drop template editor, and best-in-class deliverability.

### Official SDKs

| Language | Package |
|----------|---------|
| **PHP** | [`lettr-php`](https://github.com/lettr-com/lettr-php) |
| **Laravel** | [`lettr-laravel`](https://github.com/lettr-com/lettr-laravel) |
| **Node.js** | [`lettr-node`](https://github.com/lettr-com/lettr-node) |
| **Python** | [`lettr-python`](https://github.com/lettr-com/lettr-python) |
| **Go** | [`lettr-go`](https://github.com/lettr-com/lettr-go) |
| **Rust** | [`lettr-rust`](https://github.com/lettr-com/lettr-rust) |
| **Java** | [`lettr-java`](https://github.com/lettr-com/lettr-java) |

### Integrations

- **[WordPress Plugin](https://github.com/lettr-com/lettr-wordpress)** — Drop-in replacement for wp_mail
- **[n8n Node](https://github.com/lettr-com/lettr-n8n)** — Send emails in your n8n workflows
- **[MCP Server](https://github.com/lettr-com/lettr-mcp)** — Use Lettr from Claude, Cursor, and other AI agents
- **[Agent Skills](https://github.com/lettr-com/lettr-skills)** — Migrate providers and send emails from AI coding agents
